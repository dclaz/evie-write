# evie-write
Generating material to help toddlers write

## [Evie's Writing Workbook →](worksheets/)

A three-book series of printable A4 handwriting worksheets, from first
pencil lines, shapes and stay-inside-the-road paths, through big capital
letters with numbered stroke order, to joined-up VIC Modern Cursive words. Ready-to-print PDFs live in
[`worksheets/output/`](worksheets/output); see
[`worksheets/README.md`](worksheets/README.md) for details and how to
regenerate them.
